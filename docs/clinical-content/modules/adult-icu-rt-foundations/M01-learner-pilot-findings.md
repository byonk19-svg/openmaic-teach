# M01 learner-pilot findings

> **Status:** first-pass simulated learner debrief. This is qualitative product feedback, not a qualified clinical review, learner study, or release decision.

## Experience summary

The module was taken as an ICU RT learner through its orientation, three-question model, both Case A prediction pauses, Case B independent task, and Case C transfer framing.

### 1. Where the learner had to stop and think

Case B created the clearest pause. B1 and B2 share the same calculated 9.0 L/min, but B2 adds a communicated breathing difficulty and visible neck-muscle recruitment. The number staying unchanged while the bedside interpretation changes is the module's strongest move.

### 2. What felt too easy or obvious

Case A arithmetic is easy for an ICU RT. That is acceptable only because the lesson uses it as a setup: the real task is resisting the leap from a correct calculation to adequacy claims.

### 3. What clicked differently

Scene 2 makes the key distinction unusually compact: calculated volume, CO2 interpretation, and breathing experience/effort are related questions but not interchangeable evidence. This reframes familiar bedside information more clearly than a generic warning to “look at the whole patient.”

### 4. Case B feedback experience

The intended feedback design reads like focused clinical education, but the actual learner run returned: **“Your answer could not be safely graded or saved. The explanation remains locked. Please resubmit.”** That interrupted the learning loop and prevented a fair evaluation of the feedback voice in a real learner run.

### 5. Case C transfer

Case C feels like genuine, though modest, transfer. It changes the epistemic problem from “what does this number prove?” to “what does an older measurement still mean after conditions changed?” It preserves the value of the older gas rather than teaching that old data are useless.

### 6. Learner's own description of the lesson

Calculate accurately, then stop yourself from claiming more than the evidence earns. Use the patient and context, not just the ventilator number.

## Gut reaction

**Maybe.** The teaching spine is credible and Case B is worth learning from. The actual safe-grade/save failure disrupted the strongest independent-retrieval moment, so a fresh learner run after that runtime issue is resolved is needed before judging whether the feedback feels like a good educator.
